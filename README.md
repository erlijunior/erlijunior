### Sobre Mim 👨🏻‍💻
Sou Desenvolvedor Frontend desde 2019. Já contribuí para o desenvolvimento e manutenção de interfaces de e-commerce em produção. Meu trabalho é focado na implementação de layouts baseados em wireframes, criação de identidades visuais personalizadas e aprimoramento da experiência do usuário, utilizando tecnologias como HTML5 Semântico, CSS3, Tailwind CSS, JavaScript Moderno (ES6+), TypeScript e React.

Tenho experiência no desenvolvimento de sites estáticos e componentes responsivos, com forte foco em soluções práticas e funcionais. Tenho como missão criar interfaces digitais que sejam acessíveis e de alta performance, sempre alinhadas às necessidades do usuário, desenvolvendo código limpo, reutilizável e performático com alto impacto no produto.
